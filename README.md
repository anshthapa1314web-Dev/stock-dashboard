# Real-Time Stock Market Dashboard

A Streamlit dashboard that tracks and visualizes near real-time stock data.

## Features
- Multiple stocks at once (e.g. AAPL, MSFT, TCS.NS)
- Interactive candlestick charts (Plotly)
- SMA 20 / SMA 50 moving averages
- RSI (14) indicator
- Price change, High and Low metrics

## Tech Stack
Python, Streamlit, yfinance, Pandas, Plotly

## How to Run
```
pip install -r requirements.txt
streamlit run app.py
```
